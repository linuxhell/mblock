Versão experimental. O compilador aceita parte da sintaxe das listas. Veja as regras não suportadas abaixo. Desempenho superior ao uBlock Origin e invisibilidade a sites ainda não foram demonstrados.

Preferências

A ocultação genérica começa desativada para reduzir custo e interferência em iscas anti-adblock. Você pode ativá-la por site.

Alterações de CSS e pausa de frames já carregados exigem recarregar a página.

Diagnosticar um site

Valores dos parâmetros, fragmentos, cookies, cabeçalhos e corpos de requisição não são coletados. Caminhos podem conter dados pessoais. O JSON fica no seu computador.

Nenhuma sessão ativa.

Sobre o registro de regras

No Chrome e Edge, a identificação exata das regras pelo evento de depuração exige instalação descompactada. Erros de rede são registrados separadamente; um erro sozinho não prova que houve bloqueio pelo mBlock.

Perfil do site selecionado

A correção FC Portables substitui somente o carregador identificado pelo formato de URL. Se o site alterar esse mecanismo, será necessária outra versão da extensão.
